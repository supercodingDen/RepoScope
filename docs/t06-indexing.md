# T06 bounded indexing

The indexer consumes the persisted `repo.source.acquired` continuation after T05 commits a verified source manifest. The source consumer has its own five-attempt counter, shares the original job deadline and uses the same fenced lease and completion-before-ACK protocol as source acquisition. A staged source never becomes searchable on its own.

The handler checks the immutable manifest, reads one content-addressed blob at a time, and parses Python, TypeScript and TSX with pinned Tree-sitter grammars. Syntax errors and other text formats use labeled fallback. Chunk content retains exact source byte and line ranges, path, language, symbol and static dependency hints. `cl100k_base` counts the metadata and source together toward a 600-token target and 800-token hard cap. Embedding requests contain at most 32 chunks and 20,000 tokens. Two worker slots bound concurrent acquisition/indexing work. No imported source is executed.

Migration `0005_index` adds per-file checkpoints, 384-dimensional chunks, a versioned embedding cache, full-text and HNSW indexes, an independent indexing attempt counter and paid-embedding reservations. A checkpoint and every chunk for its file commit together under the current fence. A retry skips completed files only when the pipeline version matches. Chunk rows remain outside the public retrieval surface until one transaction verifies file and chunk cardinality, records the parser/tokenizer/embedding versions, marks the generation ready, updates the job and active repository pointer, and completes the source consumer. A generation superseded by a newer request is recorded as superseded and never replaces the active pointer. Empty eligible source sets can become ready.

The default `PROVIDER_MODE=mock` produces deterministic, labeled 384-dimensional vectors and makes no paid requests. Mock vectors test shape, persistence and replay; they do not prove retrieval relevance. To opt in to live OpenAI indexing, an operator must set `PROVIDER_MODE=openai`, `ALLOW_PAID_API_CALLS=true`, `OPENAI_API_KEY`, `EMBEDDING_DAILY_BUDGET_USD`, `EMBEDDING_PRICE_PER_MILLION_USD` and `EMBEDDING_PRICE_VERIFIED_DATE` for the indexer. The price date must be within the past seven UTC days and should reflect the current official embedding price. Every call reserves twice the estimated token cost against the UTC daily ceiling before dispatch. Settled and uncertain reservations continue to count conservatively. The adapter requests `text-embedding-3-small` at 384 dimensions with zero SDK retries and a 15-second timeout, then validates model identity, vector count, finite values and reported token usage. A provider-side tokenizer or invoice can still differ from the application estimate; the configured budget is an admission guard, not a billing guarantee.

`OPENAI_BASE_URL` and `EMBEDDING_MODEL` in the shared environment template are reserved for later milestones; T06's paid adapter uses the official endpoint and fixed model. Never place a key in source control or use live mode for routine tests. T07 will expose retrieval; T08 will execute agents. The [project status](project-status.md) records native acceptance and any unexecuted container or live-provider gates.
