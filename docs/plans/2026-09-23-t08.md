# T08 Pinned Read-Only Agent Implementation Plan

> **For agentic workers:** Implement in the owner's D-drive project with a red test before each behavior change. Execute all relevant checks before private GitHub synchronization.

**Goal:** Finish accepted runs with bounded, source-grounded read-only analysis and durable cost admission.

**Architecture:** A fenced handler owns the run workflow, typed tools enforce the persisted scope, an SDK adapter handles model turns, and PostgreSQL owns attempt/step/budget checkpoints. The existing delivery worker owns ACK and retry mechanics.

**Tech Stack:** Python 3.12, psycopg 3, pgvector, FastAPI, official OpenAI SDK, Pydantic, pytest, strict mypy, Ruff.

**Spec:** `docs/plans/2026-09-23-t08-design.md`; `docs/spec.md`; `docs/model-policy.md`; ADR-005.

## Global constraints

- No source execution, arbitrary network fetch, repository writes, or unscoped model tools.
- At most six durable model attempts and six durable tool steps within the original 120-second deadline.
- Input at most 24,000 estimated tokens, output at most 2,000, initial evidence at most 12 chunks and 8,000 tokens.
- Tool result at most 4,000 tokens and 12,000 characters; file range at most 200 lines.
- Default mock and zero paid calls; live mode needs key, opt-in, current price and atomic run/day/project reservations.
- Preserve immutable migrations 0001-0005 and T01 contracts.
