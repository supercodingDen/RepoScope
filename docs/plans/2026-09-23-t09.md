# T09 Run Timeline and CLI Implementation Plan

> **For agentic workers:** Implement this plan in the owner's D-drive project with failing tests before behavior changes and final source-only GitHub synchronization.

**Goal:** Deliver durable run progress, authenticated resumable SSE, one-hop evidence expansion, and an import-to-answer CLI demonstration.

**Architecture:** PostgreSQL owns event ordering and connection leases; the existing worker owns lease fencing and atomic terminal completion. The API streams bounded replay batches, while the agent expands only pinned dependency metadata. The CLI remains a normal API client.

**Tech Stack:** Python 3.12, psycopg 3, FastAPI/Starlette, httpx, Pydantic, pytest, strict mypy, Ruff.

**Spec:** `docs/plans/2026-09-23-t09-design.md`, `docs/spec.md`, ADR-005.

## Global constraints

- Preserve migrations 0001-0006 and existing v1 wire contracts.
- No source execution, arbitrary network fetch, repository writes, model prompt logging, or paid calls in tests.
- SSE supports replay, heartbeats, bounded batches, 24-hour terminal retention, two connections per principal, and twenty total.
- One-hop expansion adds at most four same-generation chunks and shares the twelve-chunk/8,000-token evidence limits.

## Review focus

- A forged or foreign run cursor never reveals another principal's timeline.
- A worker redelivery or deadline reconciler never creates duplicate terminal events.
- A stream disconnect frees its distributed connection slot.
- A stale cursor after retention returns 410 without replaying old events.
- An import path that escapes or points outside the pinned manifest adds no evidence.
