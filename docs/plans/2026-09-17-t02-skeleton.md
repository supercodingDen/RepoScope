## Design

Keep one Python package with API, indexer and agent entry points. The API exposes public liveness/readiness; all roles expose management health and metrics on private ports. Readiness actively probes PostgreSQL (including migration state), Redis PING and JetStream account information with bounded timeouts. Startup validates configuration and shutdown closes resources. T02 workers remain idle and do not acknowledge business events.

A one-shot migration process exclusively owns DDL, uses a transaction and advisory lock, records checksums, creates the vector extension and separate application schema, and grants only runtime DML. Business tables arrive in T03. Compose provisions dependencies with immutable image pins and persistent volumes; only the API development port binds localhost. Providers remain mock.
